## 📝 CHI TIẾT

### Script làm gì?
1. Đọc setting `showGallery` hiện tại (nếu có)
2. Scan folder `images/gallery/`
3. Tìm tất cả file ảnh (`.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`)
4. **CHỈ UPDATE** file `gallery-config.js`
5. **GIỮ LẠI** setting `showGallery` cũ
6. Backup file cũ thành `gallery-config.js.backup`
7. **KHÔNG ĐỘNG** đến `config.js`

### Ẩn/Hiện Gallery:
**Cách 1: Dùng config `showGallery`**
- Mở `gallery-config.js`
- Thay đổi: `showGallery: false` (ẩn) hoặc `showGallery: true` (hiện)
- Script sẽ giữ lại setting này khi update

**Cách 2: Tự động theo số ảnh**
- Nếu folder `images/gallery/` rỗng → tự động ẨN
- Nếu có ảnh + `showGallery: true` → tự động HIỆN

### Khi thêm ảnh:
- Chạy `./update-gallery.sh`
- Script giữ lại setting `showGallery` cũ
- Website load tất cả ảnh từ folder

## 🔧 ADVANCED FEATURES

### Show/Hide Gallery Logic
Code trong `index.html`:
```javascript
function renderGallery(galleryConfig) {
    const photos = galleryConfig.photos || [];
    const showGallery = galleryConfig.showGallery !== undefined
        ? galleryConfig.showGallery
        : true;

    // Hide gallery if disabled in config
    if (!showGallery) {
        document.querySelector('.gallery').style.display = 'none';
        console.log('Gallery hidden: showGallery is false');
        return;
    }

    // Hide gallery if no photos
    if (!photos || photos.length === 0) {
        document.querySelector('.gallery').style.display = 'none';
        console.log('Gallery hidden: No photos found');
        return;
    }

    // Show and render gallery
    document.querySelector('.gallery').style.display = 'block';
    // ... render code
}
```

**Logic ẩn/hiện:**
1. Nếu `showGallery: false` → ẨN (ngay cả khi có ảnh)
2. Nếu `showGallery: true` nhưng không có ảnh → ẨN
3. Nếu `showGallery: true` và có ảnh → HIỆN

### Timestamp trong config
Mỗi lần update, file `gallery-config.js` có timestamp:
```javascript
// Last updated: 2026-01-02 14:04:22
```
→ Dễ track lần update cuối

## 🎯 BEST PRACTICES

### 1. Đặt tên ảnh có thứ tự
```
01-couple-portrait.jpg
02-ceremony.jpg
03-reception.jpg
04-family-photo.jpg
```
→ Ảnh hiển thị đúng thứ tự

### 2. Optimize ảnh trước khi thêm
```bash
# Giảm kích thước cho web
mogrify -resize 1920x1080 -quality 85 images/gallery/*.jpg

# Sau đó update
./update-gallery.sh
```

### 3. Convert sang WebP
```bash
# Convert tất cả JPG sang WebP
for f in images/gallery/*.jpg; do
    cwebp -q 85 "$f" -o "${f%.jpg}.webp"
done

# Xóa JPG cũ (optional)
rm images/gallery/*.jpg

# Update gallery
./update-gallery.sh
```

### 4. Test không có ảnh
```bash
# Backup ảnh
mv images/gallery images/gallery-backup

# Test
./update-gallery.sh
# → Gallery should be hidden

# Restore
mv images/gallery-backup images/gallery
./update-gallery.sh
# → Gallery should appear again
```

## 🐛 TROUBLESHOOTING

### Muốn tắt gallery tạm thời (có ảnh nhưng chưa muốn show)
**Giải pháp:**
```javascript
// Mở gallery-config.js
// Thay đổi:
showGallery: false,  // Tắt gallery

// Chạy lại script vẫn giữ setting này
./update-gallery.sh
```

### Gallery không ẩn dù không có ảnh
**Giải pháp:**
```bash
# Xóa cache browser (Ctrl+Shift+R)
# Check console (F12):
# → Phải thấy: "Gallery hidden: No photos found"
```

### Gallery bị ẩn dù có ảnh
**Kiểm tra:**
```javascript
// Mở gallery-config.js
// Kiểm tra:
showGallery: true,  // Phải là true, không phải false
```

### Script không tìm thấy ảnh dù có ảnh trong folder
**Kiểm tra:**
```bash
# Xem ảnh có trong folder không?
ls -la images/gallery/

# Chạy script với debug
bash -x ./update-gallery.sh
```

### Ảnh không load sau khi update
**Giải pháp:**
```bash
# Hard refresh (Ctrl+Shift+R)
# Check file gallery-config.js có đúng path không
cat gallery-config.js
```
